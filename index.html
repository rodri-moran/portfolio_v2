Civix

Reportes urbanos para municipios · Backend distribuido con microservicios

Plataforma municipal para reportar, gestionar y dar seguimiento a incidentes urbanos. Implementé un backend basado en microservicios con Spring Boot, API Gateway, autenticación JWT, control de roles, servicios desacoplados y persistencia en PostgreSQL. El proyecto también incluyó despliegue en Render, configuración de CORS, variables de entorno y adaptación de bases de datos separadas a una única instancia PostgreSQL con schemas.

CasaAgenda

Sistema de gestión de alquileres temporales · Angular + Spring Boot

Sistema interno para administrar propiedades y reservas temporarias. Desarrollé APIs REST con Spring Boot, PostgreSQL y JPA/Hibernate, aplicando arquitectura en capas, DTOs y validaciones backend. Implementé lógica de negocio para disponibilidad por fechas, prevención de reservas superpuestas, cálculo de noches, importes, señas, saldos y manejo persistente de imágenes.

Backend Implementation

APIs REST con Spring Boot para propiedades, reservas, usuarios e imágenes Validación de disponibilidad y prevención de reservas superpuestas Cálculo automático de noches, precio total, seña y saldo restante DTOs y arquitectura por capas para separar API, negocio y persistencia

⚖️

Decision Platform

Reglas de negocio versionadas · Arquitectura desacoplada para decisiones dinámicas

Plataforma backend basada en microservicios para gestionar reglas de negocio versionadas y evaluarlas de forma desacoplada. Permite publicar reglas, consumir eventos con Kafka, evaluar decisiones dinámicas y registrar auditoría con trazabilidad mediante traceId.

Decisiones de arquitectura

rules-service como source of truth para drafts, publicación y versionado de reglas decision-service desacoplado: consume eventos Kafka y evalúa reglas activas localmente Outbox Pattern para publicar eventos de forma confiable al confirmar cambios en base de datos audit-service independiente para registrar decisiones, eventos y trazabilidad con traceId Observabilidad con Spring Actuator, Prometheus y Grafana para métricas de servicios
